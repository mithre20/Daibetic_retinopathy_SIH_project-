About This Project

A working software prototype for automated, explainable Diabetic Retinopathy screening designed for deployment through primary health centres in rural India.

🎯

Purpose

Decision-support / triage tool for a human-in-the-loop screening workflow. Every stage runs standalone and end-to-end — quality gate, lesion detection, CNN+rule grading, Grad-CAM explainability, and clinical report — all designed for <30-second ophthalmologist review.

🏥

Target Deployment

Primary health centres (PHCs) using portable, non-mydriatic fundus cameras and low-bandwidth telemedicine links. Sized for 100,000+ patients/year per district with M/M/c queueing-theory-based capacity planning.

🔬

Hybrid Architecture

CNN (global pattern recognition) + classical lesion detectors (sub-pixel microaneurysm detection, morphological top-hat, Frangi vesselness) fused at grading time. Never relies on a single technique that could miss small lesions.

📊

Explainability

Grad-CAM attention maps + lesion-level evidence + calibrated confidence, packaged as a one-page report reviewable in <30 seconds. Clinician trust requires the AI to show why, not just what.

⚠️

Honest Limitations

This web version runs image processing in-browser via Canvas API with simplified algorithms (no trained CNN). The MATLAB original requires toolboxes and labeled datasets for full deep-learning grading. Any real deployment needs regulatory clearance (CDSCO in India).

📋

Clinical Standard

Output strictly follows the International Clinical DR (ICDR) severity scale, Levels 0–4. Sensitivity is prioritized over specificity — a missed referable case risks preventable blindness.
